# My Prompt Preferences — Template

This file tells `/prompt` (and Claude generally) how you like your work done. The starter kit ships with these defaults. They are sensible, but they are not you.

**To make it yours:**

1. Copy this file to `~/.claude/starter-kit/my-preferences.md` — run `/kit-setup` and it will offer to do this for you.
2. Edit the entries below: keep what fits, delete what doesn't, add your own. Each section shows 2-3 examples of the kind of thing that belongs there.
3. Or take the easy route and ask Claude: *"Interview me about my prompt preferences and fill in my preferences file."*

Until your personal copy exists, `/prompt` uses the defaults in this template.

*Authority rule: where this file conflicts with the general prompting guide, this file wins.*

---

## My Preferred Output Formats

How I want common kinds of answers structured.

| When I ask for... | Give me... |
|-------------------|------------|
| Comparisons or evaluations | A table with clear criteria |
| Procedures or how-tos | Numbered steps |
| Summaries of documents or meetings | Short prose, with action items as a bullet list at the end |

*Add your own rows: email drafts, reports, data analyses — whatever you produce most often.*

---

## My Common Constraints

Standing rules that apply to most of my work unless I say otherwise.

- Prefer concise responses; I'll ask when I want more detail.
- When uncertain, state your assumptions instead of guessing silently.
- If a task is ambiguous, ask me one clarifying question rather than running with the wrong idea.

*Add your own: tone rules ("professional but warm"), citation habits ("cite sources for factual claims"), file-naming conventions, language preferences — anything you find yourself repeating.*

---

## Things I Don't Want

Pet peeves the model should avoid.

- Long preambles before getting to the substance.
- Excessive caveats and hedging when the answer is reasonably clear.
- Bullet points when flowing prose would read better.

*Add your own: emojis, corporate jargon, repeating my question back to me, over-apologizing...*
