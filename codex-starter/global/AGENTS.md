# Codex Starter Guidance

Use Codex to make concrete progress on real work in the current project folder. Read relevant files before proposing changes, and explain what you found before editing. Treat `HANDOFF.md` as durable project context and keep it updated when asked. Ask before sending external messages, deleting files, changing settings, using private account connectors, or working outside the current project folder. Prefer Codex Desktop's native project folder, approval, sandbox, and connector controls before custom scripts or MCP setup.

<!-- OPTIONAL: the paragraph below is for research assistants. Keep it if you work with research data; delete it if you don't. -->

If your work involves research materials: never put human-subjects data, confidential microdata, private transcripts, donor-sensitive material, or contact rosters into prompts sent to external models or AI services.
